OBS への いれかた

まるふわの 離席画面・待機画面・透過PNG は、OBS Studio に 3ステップで はいります。

3つの てじゅん

1

OBS Studio を ひらいて、したの 「ソース」の ＋ を おす。

2

うごく がめん（MP4・WebM）は メディアソース、え（PNG）は 画像 を えらぶ。

3

ダウンロードした ファイルを えらぶ。うごく がめんは ループ に チェックを いれる。

しって おくと べんり

  • そざいは 1920×1080 で つくって います。OBS の キャンバスも 1920×1080 だと ぴったり です。
  • すけて いる（透過）WebM と PNG は、ゲーム画面や カメラの うえに そのまま かさねられます。MP4 は はいけいつき です。
  • HTML の どうぐ（投票ボード・順番待ちボード・セトリ画像メーカー など）は、ブラウザ ソースで つかいます。くわしくは 商品の せつめいを みてね。
  • OBS の バージョンに よって、ボタンの なまえが すこし ちがう ことが あります。
